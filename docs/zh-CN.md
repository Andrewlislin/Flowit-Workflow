# 浮域（Flowit Workflow）

**浮域** 是 Flowit Workflow 的中文产品名。

仓库默认首页 [`README.md`](../README.md) 使用中文，并面向普通用户解释浮域是什么、与单独 Agent 的区别、各 Host 的安装/使用方式、现成工作模式和典型场景。英文版见 [`README.en.md`](../README.en.md)。

为保持兼容性，技术标识继续使用英文：

- npm 包：`@coaseedgeltd/flowit-workflow`
- CLI：`flowit-workflow`
- 协议、配置键和内部 Host/Preset ID：保持现有稳定标识

面向中文用户的产品名称、工作模式名称和说明统一使用中文。

## 三个内置工作模式

普通用户不需要记 Preset ID。面向用户展示时，使用下面三种现成工作模式：

| 工作模式 | 稳定内部 ID | 适合 |
| --- | --- | --- |
| **内容工作室** | `content-studio` | 新闻、公众号、行业内容、日报 |
| **深度研究** | `research-lab` | 市场研究、技术研究、竞品、政策分析 |
| **AI 项目小组** | `agent-team` | 编程、方案、复杂办公任务 |

浮域仍接受这些稳定内部 ID，也接受中文工作模式名和原英文显示名作为别名。

### 内容工作室

```text
发现热点
  ↓
选择题目
  ↓
研究资料
  ↓
写作
  ↓
查事实
  ↓
主编审核
```

最终产物保持人工可审查，默认不自动发布到外部平台。

### 深度研究

```text
规划问题
  ↓
搜证据
  ↓
找反例
  ↓
综合
  ↓
审核
```

强调一手证据、反方证据、不确定性和结论可追溯性。

### AI 项目小组

```text
规划
  ↓
调研
  ↓
执行
  ↓
Review
```

适合编程任务、方案制定、迁移计划和复杂的多步骤办公任务。

## 面向用户的命名原则

1. 中文产品名统一使用 **浮域**；首次出现可写作 **浮域（Flowit Workflow）**。
2. 不把 `content-studio`、`research-lab`、`agent-team` 当作主要用户名称；它们只作为稳定技术标识。
3. 中文界面优先显示 **内容工作室 / 深度研究 / AI 项目小组**。
4. 角色名称优先使用用户能直接理解的动作名称，例如“发现热点”“搜证据”“执行”，而不是要求用户理解内部 role id。
5. 不修改 npm 包名、CLI 名、协议名和已有持久化 ID，避免因品牌本地化造成兼容性迁移。
