# Permission envelope glossary

- **Capability request:** untrusted model declaration of resources needed by a run.
- **Permission envelope:** Flowit-generated bounded sandbox policy.
- **Execution grant:** signed record that the user approved one exact envelope for one normalized run.
- **Host policy evidence:** Codex-reported sandbox and approval policy used to verify enforcement.
- **Dedicated Session:** newly provisioned Codex Thread used only for the explicit run.
