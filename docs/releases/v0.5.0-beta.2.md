# Flowit Workflow v0.5.0-beta.2

`v0.5.0-beta.2` moves the public npm package family to the organization-owned
`@coaseedgeltd` scope and carries the repository forward from the GitHub-only
`v0.5.0-beta.1` prerelease.

## Highlights

- Publishes all nine packages under `@coaseedgeltd/*`.
- Keeps every workspace dependency on the same exact prerelease version in the
  packed tarballs.
- Includes the adaptive task-routing MVP and the repository-governance baseline
  now present on `main`.
- Waits for in-flight scheduler work and lease renewal writes during runtime
  disposal, preventing cleanup from racing durable state persistence.
- Preserves the existing CLI, MCP server, Claude Plugin, setup providers, and
  compatibility export surface.

## Install

Run setup directly from npm:

```bash
npx @coaseedgeltd/flowit-workflow@beta setup
```

Or install the compatibility distribution globally:

```bash
npm install -g @coaseedgeltd/flowit-workflow@beta
```

## Release integrity

The release workflow builds and validates the workspace, packs the exact npm
tarballs, verifies package names, versions, internal dependency pins and required
distribution files, generates `SHA256SUMS`, and publishes the tarballs with the
`beta` dist-tag and provenance.

`v0.5.0-beta.1` remains an immutable historical GitHub prerelease; its package
names and assets are not rewritten.
