# Flowit Workflow v0.5.0-beta.3

`v0.5.0-beta.3` turns the Studio work developed after `v0.5.0-beta.2` into a
public, installable application-package layer while preserving the existing
workflow runtime and host-adapter package family.

## Highlights

- Introduces Studio Package v1 with a declarative manifest, bounded runtime
  compatibility, strict validation, immutable staging, and explicit trust and
  permission boundaries.
- Adds transactional Studio installation, official runtime bootstrap, consumer
  install flows, package signing, and offline license verification.
- Ships the `flowit-studio` SDK/CLI for initializing, validating, and packing
  third-party-compatible Studios.
- Includes the `agent-team`, `content-studio`, and `research-lab` community
  Studios plus a minimal `research-starter` authoring example.
- Adds SkillHub distribution integration with a publisher-identity boundary and
  a separately reviewable official installer.
- Adds fail-closed first-run diagnostics, including accurate partial-Host setup
  reporting instead of treating incomplete readiness as installed.
- Keeps explicitly configured Codex executable candidates authoritative; a
  failed configured path no longer silently falls back to another `codex` on
  `PATH`.
- Strengthens execution preflight with runtime-aware selection, durable Codex
  Session provisioning, mixed-version state fencing, and receipt-based replay.

## Install

Run setup directly from npm:

```bash
npx @coaseedgeltd/flowit-workflow@beta setup
```

Or install the compatibility distribution globally:

```bash
npm install -g @coaseedgeltd/flowit-workflow@beta
```

The Studio authoring CLI is included in the root distribution:

```bash
npx --package @coaseedgeltd/flowit-workflow@beta flowit-studio --help
```

## Release integrity

The release workflow builds and validates the workspace, packs the exact npm
tarballs, verifies package names, versions, internal dependency pins and required
distribution files, generates `SHA256SUMS`, and publishes all nine tarballs with
the `beta` dist-tag and npm provenance.

This is a prerelease. Studio installation and Host execution remain fail-closed
when runtime compatibility, package trust, permissions, or Host readiness cannot
be established.
